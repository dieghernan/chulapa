Series, citations and feeds in Chulapa v2.3.0

Reading series, copyable citations, callouts and more ways to subscribe

  1. Blog
  2. Series, citations and feeds in Chulapa v2.3.0
20 nov 2026
dieghernan
Madrid, Spain

Chulapa v2.3.0 is out. You can organize a set of tutorials into a reading series, give readers a citation they can copy and send them to one page to choose a feed. I have also updated the starter sites and fixed several details around keyboard navigation, search and code copying. GitHub release · RubyGems

Give readers a path through a series

A tutorial often spans several pages. A series groups those pages in the order you choose and gives readers a collapsible index, a progress indicator and Previous and Next links. A chapter can belong to more than one series, with its own position in each. You can also label the parts to match what you publish, such as Issue for a newsletter. Series navigation guide

Make a post easier to cite

Set citation: true in a post’s front matter to show a simplified APA reference and an expandable BibTeX entry. You can supply a citation mapping with bibliographic details such as a DOI or a journal title. If the post presents the work itself, google-scholar: true also adds Google Scholar metadata. Citation and Google Scholar setup

Add callouts to longer articles

Use a callout to set off a note, tip, important detail, warning or caution. The callout class supplies the title and icon, and the colors follow the selected skin. The Kitchen Sink shows all five styles alongside citations and series navigation. Callout guide · Kitchen Sink demo

Subscribe and discover content

JSON Feed 1.1 is available at /feed.json. Share /subscribe/ to give readers a preview of recent posts and links to Atom, RSS and JSON Feed. RSS now carries the excerpt and full article in separate fields when an excerpt is available. Atom and RSS also handle author details and reading times more consistently. Feed setup · Subscribe to this blog

The theme also supplies /sitemap.txt alongside the XML sitemap. The text file lists canonical URLs and respects sitemap: false. Structured data better connects articles, authors, videos and series, and built-in collection indexes report how many items they display. Search visibility guide

Fixes you can see on an existing site

  • The Light, Dark and Auto selector shows a visible focus ring when you reach it with the keyboard. Built-in and kramdown tables of contents use the same compact spacing, and author cards wrap long names on narrow screens. Accessibility reference
  • Links in Algolia result excerpts resolve against the original article, and excerpts still appear when highlight data is missing. Fuse.js now loads as a module, and its updated scoring can change result order and counts. Algolia guide · Fuse.js guide
  • Copy buttons still give feedback when Popper fails to load. The theme now uses Bootstrap 4.6.2, Popper.js 1.16.1 and Font Awesome Free 7 by default. Changelog

Update an existing site

If you use the remote theme, set remote_theme in _config.yml to:

remote_theme: dieghernan/chulapa@v2.3.0

If you use the gem, update its entry in Gemfile:

gem "chulapa-jekyll", "~> 2.3.0"

Then run bundle update chulapa-jekyll and preview your site. If you have local copies of the script includes or the Fuse.js search page, review them before publishing. You can keep the older hosted icons with fa_version: 6. If you use a Font Awesome kit with older icon names, enable v4 compatibility in the kit settings. Upgrade checks

If you’re starting a new site, the Chulapa 101 template and the four starter examples now pin v2.3.0. The RubyGems and Netlify demos have been updated too. Chulapa 101 · Starter examples

As always, issues, suggestions and examples of sites built with Chulapa are welcome in GitHub Discussions.
