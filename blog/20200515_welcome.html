Welcome to Chulapa. This is another Jekyll theme that you can use for creating your site.

Motivation

In the last couple of years I created some tiny websites using GitHub Pages. However, I was not very happy with some of the thousands of Jekyll themes available, since I didn’t find one that met all my requirements:

  • Easy to use
  • Awesome looking
  • Plenty of add-ons
  • Feed

So, as a way to challenge myself, I decided to build this one from scratch. My main references were Beautiful Jekyll and Minimal Mistakes, that are two pretty good options, much more mature than this one and with hundreds of users. So, why not learn from them? There are pieces and components of these themes on this one.

One theme, a thousand looks

Without prior knowledge of CSS, I taught myself about rules, specificities, flexboxes, etc. through implementing Bootstrap v4 as the CSS base of Chulapa.

This is not the first theme with this implementation, but I found the way to configure it via _config.yml, which allows any user to easily change the look of the site without needing to write CSS or SCSS. On top of that, implementing Bootstrap themes from third parties is fast and reliable.

The huge advantage is that, if you give it a go, you can use Chulapa in any site you want but still define a unique look to each of them. No one could notice that the theme is the same!

Next steps

When this post was written in May 2020, Chulapa was still in development. Stable releases are now available; see the installation guide for setup instructions.

The theme currently uses Bootstrap 4 and Font Awesome 6, with support for Font Awesome 5 and optional v4 shims. See the changelog for subsequent changes.
