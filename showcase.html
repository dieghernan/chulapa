Explore these live websites built with Chulapa:

  • Stefano Travasci: A personal website with a portfolio, curriculum vitae, writings and publications.

  • YSocial: An open-source social media simulator using AI agents, with documentation and resources for studying social dynamics.

  • MerkleTree Labs: A project website focused on post-quantum cryptography and open-source security tools.

  • Metal Infestus: A metal music website with an archive and contact information (Portuguese).

  • M/S Vega: A blog about restoring a historic steel-hulled tugboat based in Helsinki (Finnish).

  • Cheung x Surya: A wedding website with the couple’s story, event details, schedules and FAQs.

  • Thibault Joubert: A blog about Microsoft 365 security, compliance and identity.

  • One World: Diego Hernangómez’s personal website covering R packages, maps and open-source projects.

  • COVID19 en España: A data visualization project with maps of COVID-19 in Spain by @dieghernan (Spanish).

  • leaflet-providersESP: A Leaflet plugin with configurations for Spanish WMS/WMTS tile providers by @dieghernan (Spanish).

  • spain-munic-bot: A project documenting a Twitter bot that maps random Spanish municipalities by @dieghernan.

  • Corona Atlas: An archived multilingual project mapping COVID-19 risk areas designated by the German government, by @rodrihgh and @dieghernan. The site remains available, but the project is discontinued and its data is no longer updated.

  • Celestial Data: A collection of celestial object data in GeoJSON format by @dieghernan.
