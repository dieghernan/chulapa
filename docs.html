How publishing fits together

GitHub stores your site’s files. Jekyll turns those files into web pages, and Chulapa provides their design and supported features. GitHub Pages hosts the finished website. With the starter template, GitHub Actions runs the publishing workflow for you when you save changes to the publishing branch. You can use the template without setting up Jekyll on your computer.

For a specific question, use search or the documentation chatbot.
