Contribute

Help improve the theme

Found a bug or a typo? Want to suggest a feature or contribute a skin to Chulapa?

Please open an issue or submit a pull request. Contributions are welcome in these areas:

  • Docs: Help improve accuracy, clarity and spelling in the documentation.

  • Skins: To create a skin, follow the theming guide and open a pull request.

  • Localization of dates: Currently, support is limited to a few languages (see here), so if you miss any language:

    • See the source code
    • Open an issue describing your implementation
    • Submit a pull request with the translation.

Reporting a bug? Include the theme version, installation method, relevant configuration and steps to reproduce it. Remove credentials and personal data from examples before sharing them.
