This is an example of how to create an index for a specific collection, in this case demo.

The following front matter selects the demo collection:

---
layout: indexcategory
title: "Demos"
subtitle: All demos in one place
permalink: /demo
include_collection: demo
og_image: /assets/img/site/banner-demos.png
---

Related and Random
This page enables both related and random cards. You can use either or both. The random cards use the same candidate pool as the related cards and are selected when the site is built, rather than each time a visitor loads the page. Use related_label and random_label to add introductory text or HTML.
