# Social banners

The brand name uses the theme's bundled Chulapa font with `liga` and `dlig`
enabled, as documented in `docs/collections/_docs/53_chulapa-font.md`.
Supporting text uses
Inter and Inter Tight with the GitDev navy and blue palette. This layout is
only for the project's social images; it does not change the reusable theme.

The original Metro photograph is downloaded from
https://images.unsplash.com/photo-1545290614-5ceedf604139 without crop or size
parameters, the same photograph referenced by `docs/index.html`.
`assets/metro-madrid-original.jpg` is the local 5716 × 3811 source.

Serve the repository root and open `scripts/social/social-card.html` at
100% browser zoom. Wait for the photo and local fonts to load. Capture:

- 1200 × 630: `docs/assets/img/site/banner.png` (encode the screenshot as PNG).
- 1280 × 640: `docs/assets/img/site/github-preview.jpg`.

Keep the Metro sign visible and check that every text line fits its column.

Chulapa typography: Ayuntamiento de Madrid, designed and produced by
Joancarles Casasín and Pablo Gámez from an idea by Silvia Fernández Palomar,
CC BY 4.0. The original license is in `assets/fonts/Chulapa/LICENCIA DE USO.txt`
at the repository root. Inter and Inter Tight retain their bundled OFL licenses.
