<span class="chulapa">Chulapa</span> v2.3.0 is out. You can organize a set of
tutorials into a reading series, give readers a citation they can copy and send
them to one page to choose a feed. I have also updated the starter sites and
fixed several details around keyboard navigation, search and code copying.
[GitHub release](https://github.com/dieghernan/chulapa/releases/tag/v2.3.0) ·
[RubyGems](https://rubygems.org/gems/chulapa-jekyll/versions/2.3.0)

## Give readers a path through a series

A tutorial often spans several pages. A series groups those pages in the order
you choose and gives readers a collapsible index, a progress indicator and
Previous and Next links. A chapter can belong to more than one series, with
its own position in each. You can also label the parts to match what you
publish, such as **Issue** for a newsletter.
[Series navigation guide]({{ '/docs/04-layouts#series-navigation' | absolute_url }})

## Make a post easier to cite

Set `citation: true` in a post's front matter to show a simplified APA
reference and an expandable BibTeX entry. You can supply a citation mapping
with bibliographic details such as a DOI or a journal title. If the post
presents the work itself, `google-scholar: true` also adds Google Scholar
metadata. [Citation and Google Scholar setup]({{ '/docs/04-layouts#make-a-post-citable' | absolute_url }})

## Add callouts to longer articles

Use a callout to set off a note, tip, important detail, warning or caution.
The callout class supplies the title and icon, and the colors follow the
selected skin. The Kitchen Sink shows all five styles alongside citations
and series navigation.
[Callout guide]({{ '/docs/49-add-alert#use-a-callout' | absolute_url }}) ·
[Kitchen Sink demo]({{ '/demo/15-kitchen-sink' | absolute_url }})

## Subscribe and discover content

JSON Feed 1.1 is available at `/feed.json`. Share `/subscribe/` to give
readers a preview of recent posts and links to Atom, RSS and JSON Feed. RSS
now carries the excerpt and full article in separate fields when an excerpt
is available. Atom and RSS also handle author details and reading times
more consistently. [Feed setup]({{ '/docs/56-publish-feeds' | absolute_url }}) ·
[Subscribe to this blog]({{ '/subscribe/' | absolute_url }})

The theme also supplies `/sitemap.txt` alongside the XML sitemap. The text
file lists canonical URLs and respects `sitemap: false`. Structured data
better connects articles, authors, videos and series, and built-in collection
indexes report how many items they display.
[Search visibility guide]({{ '/docs/65-search-visibility#text-sitemap-development' | absolute_url }})

## Fixes you can see on an existing site

- The Light, Dark and Auto selector shows a visible focus ring when you reach
  it with the keyboard. Built-in and kramdown tables of contents use the same
  compact spacing, and author cards wrap long names on narrow screens.
  [Accessibility reference]({{ '/docs/48-accessibility-reference' | absolute_url }})
- Links in Algolia result excerpts resolve against the original article, and
  excerpts still appear when highlight data is missing. Fuse.js now loads as
  a module, and its updated scoring can change result order and counts.
  [Algolia guide]({{ '/docs/37-algolia-search' | absolute_url }}) ·
  [Fuse.js guide]({{ '/docs/12-fusejs-search' | absolute_url }})
- Copy buttons still give feedback when Popper fails to load. The theme now
  uses Bootstrap 4.6.2, Popper.js 1.16.1 and Font Awesome Free 7 by default.
  [Changelog](https://github.com/dieghernan/chulapa/blob/v2.3.0/CHANGELOG.md)

## Update an existing site

If you use the remote theme, set `remote_theme` in `_config.yml` to:

```yaml
remote_theme: dieghernan/chulapa@v2.3.0
```

If you use the gem, update its entry in `Gemfile`:

```ruby
gem "chulapa-jekyll", "~> 2.3.0"
```

Then run `bundle update chulapa-jekyll` and preview your site. If you have
local copies of the script includes or the Fuse.js search page, review them
before publishing. You can keep the older hosted icons with `fa_version: 6`.
If you use a Font Awesome kit with older icon names, enable v4 compatibility
in the kit settings. [Upgrade checks]({{ '/docs/07-migration#upgrade-to-v230' | absolute_url }})

If you're starting a new site, the <span class="chulapa">Chulapa</span> 101
template and the four starter examples now pin v2.3.0. The RubyGems and Netlify
demos have been updated too.
[<span class="chulapa">Chulapa</span> 101](https://github.com/dieghernan/chulapa-101) ·
[Starter examples]({{ '/docs/08-starter-examples' | absolute_url }})

As always, issues, suggestions and examples of sites built with
