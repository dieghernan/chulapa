The <span class="chulapa">Chulapa</span> documentation now has an AI assistant.
You can open it from the sparkle button on the homepage or documentation pages
and ask about installation, skins, configuration, layouts and other documented
features.

Try a specific question such as “How do I change my site's skin?” or “How do I
add a local video?” The assistant can provide short explanations, code examples
and links to the relevant documentation. Each question is independent, so include
the details it needs rather than relying on an earlier message.

The assistant uses Cloudflare Workers AI with a reviewed summary of the docs.
Questions are sent to Cloudflare for processing. Answers can contain mistakes;
check the linked documentation, especially before changing your configuration.
Site search remains available when you want to explore the original pages.

This is an addition to the documentation site. It is not bundled with the
reusable theme and does not require an AI account to use
<span class="chulapa">Chulapa</span> on your own site.

I wrote a more personal account of the development, including context selection,
answer testing and the mobile interface, on my blog:
[Building a documentation chatbot for <span class="chulapa">Chulapa</span>](https://dieghernan.github.io/202610_building-a-documentation-chatbot/).
