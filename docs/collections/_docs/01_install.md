Choose the route that matches your site. These are alternatives, not steps to
complete in sequence.

| Your starting point | Use |
| --- | --- |
| Your first website; no local setup | [Publish your first site](./00-start) |
| An existing Jekyll site using a remote theme | [Install using a remote theme](./20-remote-theme) |
| An existing site built with a theme gem | [Install using the theme gem](./21-gem-theme) |
| A site moving from another theme | [Migration guide and checklist](./07-migration) |

## 1. Use our GitHub template

The [browser tutorial](./00-start#start-with-the-github-template) publishes a
personal blog using a GitHub account. The template includes sample articles,
an About page, search and a ready-made design.
[Preview the template](https://dieghernan.github.io/chulapa-101/).

## 2. Remote theme method

Follow [Install using a remote theme](./20-remote-theme) for dependencies,
configuration, preview and publication. The guide pins `@v2.1.0`; an unpinned
remote theme follows development updates on `main`.

## 3. Gem-based method <i class="fa-solid fa-gem fa-xs"></i>

Follow [Install using the theme gem](./21-gem-theme) to install a released version,
enable its plugin and verify publication. Features marked **v2.1.1-dev** require
development changes and are not included in the v2.1.0 release.
