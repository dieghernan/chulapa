Use this guide for an existing Markdown post or page using kramdown, as in the
sample configuration. Edit the article body below its settings block.

## Add a matching reference and definition

Insert a reference after the sentence and a definition elsewhere in the same
article, separated from surrounding paragraphs:

```markdown
This claim has a source.[^source]

[^source]: Details about the source.
```

Replace the sample sentence and note with your content. The label `source` must
match in both places; use a different label for each separate note. The rendered
number is generated by the Markdown parser, not by the label's text.

## Publish and verify

Commit on the publishing branch, wait for **Actions** to succeed and open the
published article. Follow the superscript link to the note, then its return link
to the sentence. Check that both links are keyboard reachable.

If the notation remains plain text or the note is missing, check matching labels
and your parser's footnote support in [the Markdown reference](./markdown-cheatsheet).
For an old public page, use [publishing checks](./42-unpublished-changes).

Example output:

This claim has a source.[^source]

[^source]: Details about the source.
