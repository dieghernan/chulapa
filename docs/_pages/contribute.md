Found a bug or a typo? Want to suggest a feature or contribute a skin to <span
class="chulapa">Chulapa</span>?

Please [open an issue](https://github.com/dieghernan/chulapa/issues/new/choose)
or submit a pull request. Contributions are welcome in these areas:

- **Docs**: Help improve accuracy, clarity and spelling in the documentation.

- **Skins**: To create a skin, [follow the theming guide]({{ "/docs/03-theming" | relative_url }}) and open a pull request.

- **Localization of dates**: Currently, support is limited to a few languages ([see here](https://dieghernan.github.io/chulapa/docs/04-layouts#localization-of-dates)), so if you miss any language:
   - See [the source code](https://github.com/dieghernan/chulapa/blob/main/_includes/snippets/datetranslate.html)
   - [Open an issue](https://github.com/dieghernan/chulapa/issues/new/choose) describing your implementation
   - Submit a pull request with the translation.

**Reporting a bug?** Include the theme version, installation method, relevant
configuration and steps to reproduce it. Remove credentials and personal data
from examples before sharing them.
