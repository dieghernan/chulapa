Try the classic navbar at the top of this page. On a narrow screen, focus Toggle navigation and press Enter or Space to show the links. Open a dropdown with Enter or Space, use the arrow keys to move between its links, and press Escape to close it.

This demo follows the development version after v2.1.0. Its updated controls are not included in the v2.1.0 gem or a remote theme pinned to that release.

The navbar stays at the top while you scroll. It uses this site's menu entries and navbar.expand breakpoint, rendered by the same classic component as a standard theme page.

For your own menu, follow Add or change a menu link. Style and breakpoint values are in the navbar reference.

Front matter for this demo

This demo selects the theme's classic navbar while the rest of the documentation can use a floating menu. For a standard layout, omit navbar.style in _config.yml to use the classic navbar.
