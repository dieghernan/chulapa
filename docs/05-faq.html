Editing and publishing

How do I switch from another Jekyll theme?

Follow the migration guide and checklist to adapt your configuration, layouts and integrations. If the build or design is unexpected, check the common migration problems.

How do I change my site’s name or author?

Follow Change your site’s name and author to edit the existing settings, match the home-page heading and verify publication. The complete field reference remains available for option lookup.

How do I add a new article or page?

Use Create and publish a post for a dated article, or Create a page and link it from the menu for standalone content such as About or Contact. Each guide includes a complete file and published-result checks.

Why can I not see my changes?

Follow Find changes missing from your website to check the saved commit, publishing run, website address and post date. For a configuration parse error, use Fix a YAML configuration error.

Why is my photograph missing?

The image guide covers missing uploads, filename capitalization and repository paths. If the whole article is stale, use the publishing checks.

How do I change the colors or design?

Use Choose a skin for a complete design, Change a color for one adjustment, or Change the fonts for typography. Existing overrides are explained in How skins and overrides interact.

How do I…

The answers below cover formatting, optional integrations and advanced customization. Skip to the task you need.

…start with Markdown?

The theme Markdown cheatsheet shows syntax and output. The external Markdown cheatsheet and kramdown reference cover more syntax. The sample configuration uses kramdown with its GFM parser; accepted syntax depends on your Markdown configuration.

For a complete file with its settings block and text, see Create a post.

…add custom HTML, analytics, CSS or JavaScript to every page?

Follow Add custom HTML to the page head for an editing procedure. Look up the three HTML hooks, custom CSS file and insertion order in Custom hooks reference. Built-in GoatCounter and Google Analytics have separate setup guides; adding their scripts a second time can duplicate counts.

…add favicons?

Follow Add a favicon to upload the package, preserve existing head snippets and verify the generated addresses with baseurl.

…add an alert box?

Follow Add an information or warning box for the attribute placement, spacing and published-result checks.

…add a caption?

Follow Add a caption below an image. Keep descriptive alternative text as well as the visible caption.

…add a footnote?

Follow Add a footnote to an article for a matching reference and definition and a live output example.

...use Chulapa font on my theme?

Follow Use the bundled font for heading configuration, ligatures and the chulapa class on selected text. Other families are covered by Change the fonts.

…add a Font Awesome icon in Markdown?

Follow Add a Font Awesome icon for an article example, accessible text and missing-icon checks. Version and kit fields remain in the Font Awesome reference.

…have a quick preview of a page of my site with any skin?

The skin previews compare designs on this documentation site. They do not save a design to your site; Choose a skin covers applying one to your own pages.

…find an error in my _config.yml file?

Follow Fix a YAML configuration error. It covers locating the failing edit, checking indentation/quotes/duplicate sections and rebuilding. Valid YAML alone does not establish valid skin names, provider IDs or field locations.

…know which version of the theme I am using?

Follow Check which theme version your site uses to inspect the remote-theme selection, resolved gem and published HTML marker. The marker does not identify an exact unpinned commit or local overrides.

…use jekyll-feed instead of Chulapa’s feeds?

Use Publish posts in the built-in feeds for article selection and subscription links. To preserve an existing plugin feed, follow Keep a jekyll-feed subscription address; keep its output separate from the theme’s /atom.xml and /rss.xml.
