Lookup for selected variables accepted by chulapa-skin.vars in _config.yml, not page front matter. Hex colors and Sass expressions such as sizes/font lists are quoted strings; switches are YAML booleans. Names omit the Sass $ prefix and trailing semicolon. For editing and publishing, use Change a color or Change fonts. Mapping syntax specimen:

chulapa-skin:
  vars:
    primary: "#345678"
    navbar-chulapa-hover-bg-color: "#234567"
    chulapa-toc-bg: "#f5f5f5"
    font-size-base: "1.1rem"
    enable-rounded: false

Unless a skin or vars supplies a value, the navbar background uses primary, the footer and hero backgrounds use the navbar background and the landing page background uses the hero background. Many text colors are derived from these backgrounds. Explicit component colors supplied by a skin or vars keep their assigned values.

Some values cannot be overridden through vars. Helpers such as landingpage-card-bg and cactus-btn-text are calculated by the theme; adding them to chulapa-skin.vars has no effect. Use the options in the table or custom CSS instead. The complete Chulapa variable reference includes these calculated values.

These inputs belong to site configuration, not article settings. Page options: Layouts and snippets.
