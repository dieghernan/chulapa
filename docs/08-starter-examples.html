Starter examples reference

These examples are for people who already use Jekyll. Each folder contains a Gemfile, _config.yml, home page and sample content. They have no deployment workflow. The separate Chulapa 101 template is a ready-made personal blog with publishing configured; it is not a selector for these four examples.

Example Included content Annotated demo Source
Personal blog A recent-post card index and a first story Blog demo personal-blog
Technical blog A post with code, Mermaid, MathJax and a TOC Technical demo technical-blog
Portfolio A projects collection, card index and two project pages Portfolio demo portfolio
Project A landing page with source and getting-started buttons Project demo project

The demos display source specimens and sample content inside this documentation site; they do not reproduce each standalone site’s home page or skin. The portfolio demo’s illustrative cards link to source files; the copied site’s cards link to generated project pages. The project demo’s Get started button opens fictional project copy, not the website setup guide.

All four folders have identical dependency lists: Jekyll ~> 4.4, remote-theme, include-cache, GitHub metadata, pagination, sitemap, the GFM Markdown parser, WEBrick, Windows timezone data and ostruct. The Gemfile installs dependencies; the configuration enables the listed plugins. Remote themes do not install gems.

The examples use the development remote theme with explicit dependencies. Mermaid requires v2.2.0. A portfolio’s cards do not provide filtering, and the project example does not supply a documentation sidebar.

For setup, use Run and publish a starter example. For a first website without local installation, use the browser tutorial.
