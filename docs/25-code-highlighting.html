Change code highlighting

  • Select the style
  • Publish and check

Use this guide for an already published site. In your repository’s Code tab, open _config.yml and click the pencil. Edit existing entries and preserve unrelated settings; do not add a second chulapa-skin section.

Select the style

Choose a style from the highlighting previews. Change highlight under your existing chulapa-skin section:

chulapa-skin:
  highlight: zenburn

Keep your skin and other settings. default is the default highlighting style. The preview selector changes only the demo, not your site’s configuration.

Publish and check

Save with Commit changes on your publishing branch. Wait for the latest run in Actions to succeed, then open your website from Settings > Pages. Open a page containing a fenced code block with a language name, such as ruby. Check the code text, background and contrast, including on a narrow screen. A highlighting style controls code appearance; it does not change the font or colors of ordinary article text. For local preview, restart Jekyll after changing _config.yml: these settings are compiled into CSS during the build. If changes are missing, use the publishing checks.

For the setting, see the highlighting reference.
